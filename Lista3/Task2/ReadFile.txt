Function: ReadFile()
Location: https://docs.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-readfile

Description:
ReadFile() reads data from a file. The function starts reading at the position indicated by the file pointer. After the read operation is complete, the file pointer is adjusted by the number of bytes actually read.

Syntax:
BOOL ReadFile(
  HANDLE       hFile,
  LPVOID       lpBuffer,
  DWORD        nNumberOfBytesToRead,
  LPDWORD      lpNumberOfBytesRead,
  LPOVERLAPPED lpOverlapped
);

Parameters:
- hFile: Handle to file (from CreateFile())
- lpBuffer: Pointer to buffer that receives data
- nNumberOfBytesToRead: Number of bytes to read
- lpNumberOfBytesRead: Pointer to variable that receives number of bytes read
- lpOverlapped: Pointer to OVERLAPPED structure (NULL for synchronous I/O)

Return Value:
- On success: Returns TRUE
- On error: Returns FALSE, use GetLastError() for details

Behavior:
- Reads at current file position, advances file pointer by bytes read
- May read fewer bytes than requested (especially for non-regular files)
- Returns TRUE with zero bytes read at end of file (EOF)
- Blocking operation (waits until data available)

Example:
DWORD dwBytesRead = 0;
char buffer[256];
HANDLE hFile = CreateFileA("file.txt", GENERIC_READ, FILE_SHARE_READ,
                           NULL, OPEN_EXISTING, FILE_ATTRIBUTE_NORMAL, NULL);
if (hFile == INVALID_HANDLE_VALUE) {
    printf("CreateFile failed\n");
    return;
}
if (ReadFile(hFile, buffer, sizeof(buffer)-1, &dwBytesRead, NULL)) {
    buffer[dwBytesRead] = '\0';
    printf("Read: %s\n", buffer);
} else {
    printf("ReadFile failed: %ld\n", GetLastError());
}
CloseHandle(hFile);
