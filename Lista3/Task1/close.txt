Function: close()
Location: https://man7.org/linux/man-pages/man2/close.2.html

Description:
The close() function closes a file descriptor, releasing all locks held by the process on the file associated with the descriptor. If it is the last open file descriptor for the file, the file table entry for the file is deallocated.

Syntax:
int close(int fd);

Parameters:
- fd: File descriptor to close (from open())

Return Value:
- On success: Returns 0
- On error: Returns -1, sets errno to indicate the error

Behavior:
- Closes the file descriptor and makes it available for reuse
- All locks held by process on file are released
- If fd is not open: returns error EBADF
- Close is called automatically when process terminates
- Should always be called to avoid file descriptor leaks

Common Errors:
- EBADF: fd is not a valid open file descriptor
- EIO: I/O error occurred

Important Notes:
- Always close files when done to free system resources
- Forgetting to close files can exhaust file descriptor limits
- In case of error, errno is set but fd is still closed

Example:
int fd = open("file.txt", O_RDONLY);
if (fd == -1) {
    perror("open");
    return;
}
// ... read from file ...
if (close(fd) == -1) {
    perror("close");
}
