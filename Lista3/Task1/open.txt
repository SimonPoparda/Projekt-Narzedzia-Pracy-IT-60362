Function: open()
Location: https://man7.org/linux/man-pages/man2/open.2.html

Description:
The open() function opens a file descriptor for the file specified by pathname. It can create a new file if O_CREAT flag is provided.

Syntax:
int open(const char *pathname, int flags);
int open(const char *pathname, int flags, mode_t mode);

Parameters:
- pathname: Path to the file to open (string)
- flags: Options controlling how the file is opened (O_RDONLY, O_WRONLY, O_RDWR, O_CREAT, O_APPEND, etc.)
- mode: File permission bits when creating a new file (octal, e.g., 0644)

Return Value:
- On success: Returns a non-negative file descriptor (integer)
- On error: Returns -1, sets errno to indicate the error

Common Flags:
- O_RDONLY: Open for reading only
- O_WRONLY: Open for writing only
- O_RDWR: Open for reading and writing
- O_CREAT: Create file if it doesn't exist
- O_APPEND: Append to end of file
- O_TRUNC: Truncate file to zero length

Example:
int fd = open("myfile.txt", O_RDWR | O_CREAT, 0644);
if (fd == -1) perror("open");
