Function: read()
Location: https://man7.org/linux/man-pages/man2/read.2.html

Description:
The read() function reads up to count bytes from a file descriptor into the buffer pointed to by buf. It attempts to read from the current file offset.

Syntax:
ssize_t read(int fd, void *buf, size_t count);

Parameters:
- fd: File descriptor from which to read (from open())
- buf: Pointer to buffer where data will be stored
- count: Maximum number of bytes to read

Return Value:
- On success: Returns the number of bytes read (0 if EOF, may be less than count)
- On error: Returns -1, sets errno to indicate the error

Behavior:
- Reads from current file position, advances offset by number of bytes read
- Returns 0 at end of file (EOF)
- May return fewer bytes than requested (e.g., if reaching EOF)
- Block if data not immediately available (for sockets, pipes, devices)

Example:
char buf[256];
int fd = open("file.txt", O_RDONLY);
ssize_t bytes = read(fd, buf, sizeof(buf)-1);
if (bytes > 0) {
    buf[bytes] = '\0';
    printf("Read: %s\n", buf);
}
close(fd);
